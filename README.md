# Project Title

## Project Overview
This repository contains a .NET 9 sample solution composed of an API and a background Worker, designed for containerized deployment on AWS ECS with Amazon SQS for asynchronous processing.

## Run Commands
Use `dotnet build` and `dotnet run` commands for local execution and `docker build` and `docker run` commands for containers.

## Deploy Commands
Use AWS ECR and ECS CLI commands to build, push, register task definitions, and update ECS services.

## Additional Information
For more details on setting up your environment and configuring the services, please refer to the documentation in the `docs` directory.
